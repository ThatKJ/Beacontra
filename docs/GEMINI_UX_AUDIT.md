# Gemini UX Audit

**STATUS: PENDING IMPLEMENTATION**

Awaiting frontend implementation (`src/`).

This document will evaluate the UI as a first-time user:
- Do I know what this product does within 5 seconds?
- Do I know what to type/click?
- Is the first screen overloaded?
- Is the core workflow obvious?
- Are loading states good?
- Can I tell whether results are live?
- Are sources visible?
- Can I understand WHY a result was produced?
- Are charts meaningful?
- Is information hierarchy strong?
- Is mobile/responsive behavior acceptable?
- Is anything decorative pretending to be useful?
- Are there dead controls?
- Are there fake statistics?
- Are there placeholder sections?
- Would the demo require the presenter to explain what the viewer should be seeing?

Issues will be classified:
- **P0** — demo/product breaking
- **P1** — seriously weakens quality
- **P2** — polish
- **P3** — optional

Format for issues:
- **PROBLEM:**
- **USER IMPACT:**
- **FILE/SCREEN:**
- **RECOMMENDED FIX:**
- **ACCEPTANCE CRITERIA:**
